О проекте
Жанр: Puzzle / Logic / Board Game
Движок: Unity
Язык: C#
Платформа: WebGL / PC / Mobile

Управление
Мышь / палец — клик по клетке для хода

Режимы игры
👤 Один игрок — игра против ИИ

👥 Два игрока — игра на одном устройстве

Уровни сложности ИИ
Сложность	Описание
🟢 Новичок	Случайные ходы (почти не защищается)
🟡 Любитель	Блокирует победу игрока, но не строит свои линии
🟠 Средний	Строит свои линии и блокирует игрока
⚫ Невозможный	Эксперт + просчёт на 2 хода вперёд + психология (заманивает в ловушки)
Особенности
Звуки и музыка (клик по клетке, победа, ничья, проигрыш)
